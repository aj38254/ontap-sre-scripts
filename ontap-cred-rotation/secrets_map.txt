#   <cluster-as-in-the-inventory>   <secret-name>   [user]

# The user is inferred from the secret name (-SRE-RW -> sre-rw, -SRE-RO ->
# sre-ro, anything else -> admin), so the third column is only needed to
# override that. Several lines for one cluster are fine.

# This matters more here than anywhere else: never rotate an account you cannot
# find a secret for. A new password with nowhere to be stored is not a rotation,
# it is a lockout waiting to happen. Find the secret first, add a line below,
# and only then change the password.
#
